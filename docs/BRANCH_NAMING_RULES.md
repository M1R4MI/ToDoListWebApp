#Rules for the branch naming
---

Іменування гілок
Формат: <тип>/<номер задачі>/<короткий опис>

fix/34/add-migrations feat/122/like-streetcode

Тип: 
- feat — нова функціональність
- fix — виправлення
- chore — тех. обслуговування або non-code завдання
- test — якщо додає або змінює тести
- style — зміни в стилі коду або форматуванні
- build — впливає на build системи або розгортання
- docs — зміни в документації
- ops — devops, інфраструктура або резервне копіювання
- perf — вплив на продуктивність
- refactor — будь-що інше

Номер — з дошки задач. Опис англійською, малими літерами, слова через дефіс
